# Echo-Infinity Streaming Inference: Exact Rollout, Eviction, Memory, and Long-Stream Semantics

## Scope and execution path

**OBSERVED.** The requested single-prompt entry point constructs `CausalInferencePipeline`, loads the generator/EMA and optional query-memory weights, applies LoRA plus an optional separately stored `query_memory_encoder`, allocates a full latent-noise tensor, and calls `pipeline.inference(...)` once per sample (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/inference/inference.py:75-128`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/inference/inference.py:148-175`). `CausalInferencePipeline` creates a causal `WanDiffusionWrapper` and installs `QueryMemoryEncoder` when `memory_kwargs.enabled` is true (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:8-23`). The supplied inference YAMLs do not set `model_kwargs.use_infinite_attention`; therefore the wrapper's default `False` selects `wan/modules/causal_model.py`, not the alternate inference-only `CausalWanModelInfinityMemory` path (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/utils/wan_wrapper.py:106-120`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:9-15`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference_240s.yaml:9-15`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity_inference_std.yaml:9-13`).

**OBSERVED ABSENCE.** The config key `use_evicted_kv: false` is not a behavioral switch in this path: `QueryMemoryEncoder.__init__` reads its supported options without reading `use_evicted_kv`, while `update()` unconditionally consumes its `evicted_k`/`evicted_v` arguments (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:38-67`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:124-142`). Thus the implemented query memory is in fact driven by evicted KV despite that YAML value (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:31-50`).

## 1. Streaming rollout loop

### 1.1 Units, block size, and output length

**OBSERVED.** The loop operates on VAE latent-time frames, not decoded RGB frames: the CLI samples `[batch, num_output_frames, 16, 60, 104]` noise, and only after generation passes the latent output to the VAE (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/inference/inference.py:163-175`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:107-112`). All supplied inference configs use `num_frame_per_block: 3`; the short, 30-second, and 240-second configurations request 21, 120, and 960 latent frames respectively (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity_inference_std.yaml:2-18`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:1-20`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference_240s.yaml:1-19`). The long-stream writer explicitly expects `4 * num_output_frames - 3` decoded frames at 16 fps, confirming the temporal VAE expansion used operationally (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/inference/stream_long/inference_long_stream.py:210-214`).

### 1.2 Cache initialization and one-block rollout

**OBSERVED.** `inference()` requires divisibility by the 3-latent block size, computes `num_blocks`, and initializes one self-attention KV cache and one text cross-attention cache per transformer block (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:39-43`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:60-80`). For local attention, physical self-attention cache capacity is `local_attn_size * 1560`; with the long configs this is 12 latent-frame slots per layer, each K/V tensor shaped `[B, 12*1560, 12, 128]` across 30 layers (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:60-70`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:133-149`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:9-14`).

**OBSERVED.** For each 3-latent block, the pipeline takes that block's initial noise and executes every configured denoising step in sequence. Every nonfinal step predicts `x0`, re-noises that prediction at the next step with fresh Gaussian noise, and the final step leaves `denoised_pred` as the block output (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:79-92`). The YAML list has four entries, and `warp_denoising_step: true` remaps them through the scheduler's 1000-step shifted schedule before rollout (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:1-7`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:23-28`). Therefore each output block makes four denoising transformer calls.

**OBSERVED.** After all four denoising calls, the block output is stored, then a fifth transformer call runs on `denoised_pred` at `context_noise`; every supplied inference YAML sets `context_noise: 0` (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:92-100`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:21-26`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity_inference_std.yaml:19-24`). Only after this context-cache call does `current_start_frame` advance by three (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:93-100`).

### 1.3 Per-forward cache read/write order

**OBSERVED.** Relative-RoPE mode stores pre-RoPE K in the persistent cache (`k_for_cache = k`), computes `is_recompute` from absolute `global_end_index`, and builds a temporary cache clone containing the current call's rolled/inserted K/V (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:124-168`). Attention reads that temporary view, so the current block can attend to its tentative current-call KV as well as sink, memory, and recent KV (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:203-224`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:250-310`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:354-354`).

**OBSERVED.** Persistent cache mutation is deliberately deferred. All transformer blocks first return update descriptors; after the block loop, memory extraction/update occurs from the still-old persistent cache, and only then `_apply_cache_updates` rolls/inserts every layer and advances `global_end_index`/`local_end_index` (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:750-782`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:785-837`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:652-684`). Text cross-attention has separate caching: its projected text K/V are computed once when `is_init` is false and reused thereafter (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/model.py:91-109`).

## 2. Exact eviction and memory-write timing

### 2.1 The call sequence

**OBSERVED.** The previous block is fully denoised before its durable context KV is produced: four denoising forwards finish, then the explicit timestep-0 context forward overwrites/commits that block's cache, and then the loop advances (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:83-100`). Recompute protection prevents a later denoising pass at `current_start > 0` from overwriting sink slots, but permits rewriting the current non-sink slots (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:138-168`).

**OBSERVED.** Eviction is not invoked immediately after that context forward. It is detected inside the next block's first denoising transformer call when `num_new_tokens + local_end_index` exceeds physical cache capacity; the code computes `num_evicted_tokens`, makes a rolled temporary view, and returns a `roll_and_insert` descriptor (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:138-154`). With sink 3, physical capacity 12, and block size 3, occupancy reaches 12 latent frames after blocks starting at 0, 3, 6, and 9; the first eviction is therefore triggered by the first denoising call for the block starting at latent frame 12 (**INFERRED by direct substitution into the cited cache equations and config values**) (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:7-14`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:79-100`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:134-154`).

**OBSERVED.** After all 30 transformer blocks of that triggering call, the model computes how many chronological frames crossed the nine-frame recent-window boundary (`(max_attention_size - sink_tokens) / 1560`), advances `_ei_prev_window_start`, and reads exactly those outgoing K/V from the old persistent cache (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:785-825`). For query memory it selects `last_block_idx`, so only the last transformer's outgoing self-attention K/V are sent to `QueryMemoryEncoder.update`; sink K/V are also passed but are ignored because `use_sink_anchor: false` (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:788-828`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:42-45`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:137-142`). The persistent cache roll/insert happens after this memory update (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:816-837`).

### 2.2 Which timestep's KV enters memory?

**OBSERVED.** Although eviction is triggered during the next block's first denoising call, the extracted old-cache K/V belong to the evicted previous latent block after its final `context_noise=0` recache. This follows from the explicit post-denoising context call and deferred old-cache read described above (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:84-100`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:816-828`). It is therefore timestep-0 context-pass KV from the last transformer layer—not KV from the last configured denoising timestep—that drives the memory update.

**OBSERVED.** The memory K/V used by a transformer call are materialized before the block loop from the encoder state that existed at call entry (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:726-740`). The eviction-triggering call then updates the recurrent query state only after all blocks (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:785-828`). Consequently, newly compressed information is not visible to attention in the same triggering call; it first becomes visible on the next denoising call for that same 3-frame block, when `get_kv()` is run again (**INFERRED directly from the cited ordering**) (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:726-751`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:194-212`).

**OBSERVED.** Subsequent denoising/context calls at the same absolute `current_start` are recomputations, so they rewrite the current block but do not advance the chronological window or update memory again; `num_exited_frames` is zero after `_ei_prev_window_start` was advanced by the first call (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:138-168`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:797-816`). In steady state this yields exactly one recurrent memory update per newly generated 3-latent block, plus memory reads on the model calls.

## 3. Mature/steady phase and bounded RoPE

### 3.1 Fixed three-tier layout

**OBSERVED.** With `local_attn_size=12` and `sink_size=3`, the attention code reserves three frame slots for sink and derives a nine-frame recent budget from the remaining `max_attention_size` (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:169-224`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:9-14`). Query memory has a fixed `Q_frames * tokens_per_frame = 3 * 1560 = 4680` token state, and its update is a gated replacement of that fixed state rather than append-only storage (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:38-68`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:144-158`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:177-192`). After warm-up, every new 3-frame block rolls exactly three non-sink frames, leaves physical `local_end_index` at the 12-frame capacity, and evolves the same 3-frame-equivalent query state (**INFERRED by substituting the fixed block/capacity values into the roll equations**) (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:138-154`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:50-55`).

### 3.2 RoPE assignment over unbounded absolute length

**OBSERVED.** Relative positions are recomputed on every call as follows: `q_last = min(current_start + B - 1, pmax - 1)`, `q_start = q_last - B + 1`; recent keys end at `q_last`; and, when memory is active, its positions are the `N_Q` slots immediately before the recent window. Sink starts at zero (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:63-78`). The long configs set `B=3`, `N_Q=3`, sink 3, and `pmax=21` (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:7-14`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:31-39`).

**OBSERVED.** Because relative mode caches raw pre-RoPE K, each call re-applies temporal RoPE separately to sink at `start_frame=0`, recent K at the newly computed `local_start`, memory K at `mem_start`, and queries at `q_start` (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:124-133`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:203-218`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:250-300`). This is positional recycling by re-rotation of raw K, not in-place rotation of already-RoPE'd cached keys.

**INFERRED.** At block start 18 and thereafter, `q_last` is clamped to 20. In the full steady layout, sink frames use IDs 0..2, the three memory frames use 9..11, the nine recent frames use 12..20, and the current three queries use 18..20; IDs 3..8 are intentionally unused after saturation. This follows exactly from `R=9`, `N_Q=3`, `N_S=3`, `B=3`, and the cited position equations (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:63-78`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:250-268`). Absolute `global_end_index` and `_ei_prev_window_start` continue increasing as scalar counters, but attention's temporal RoPE IDs remain bounded at 0..20 (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:681-684`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:797-804`).

### 3.3 Match to training

**OBSERVED.** Long-video training uses the same block size 3, local size 12, sink size 3, Relative RoPE with `pmax=21`, query-memory size 3 frames, and timestep-0 context cache (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long.yaml:52-62`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long.yaml:106-125`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/default_config.yaml:4-10`). Its inner rollout has the same per-3-frame denoising loop followed by a no-grad context forward (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/streaming_training.py:40-77`). Training sequences are streamed in outer chunks of 21 latent frames up to 240, with at least 18 new frames, so the first eviction at frame 12 and the RoPE-clamped phase from frame 18 occur inside training sequences rather than only at inference (**INFERRED from the configured lengths and the cited transition equations**) (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long.yaml:43-49`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long.yaml:88-93`).

**OBSERVED.** Training allocates a larger physical cache, `(local_attn_size + slice_last_frames) * 1560 = 33` frame slots, while still setting each attention module's active maximum to 12 frames; the chronological oldest-recent calculation therefore emits memory at the same nine-frame logical boundary even before physical cache rolling begins (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/streaming_training.py:24-26`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/streaming_training.py:90-94`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/streaming_training.py:117-137`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:792-828`). The recurrent state is detached every outer chunk under the configured `bptt_clips: 1`, but its value persists (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/streaming_training.py:212-218`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long.yaml:117-123`).

**OBSERVED DIFFERENCE.** The 5-second standard inference config does not enable `relative_rope`, whereas the long inference configs and long-training config do (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity_inference_std.yaml:9-13`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:9-15`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long.yaml:57-62`). Therefore bounded/recycled Relative RoPE is a long-model behavior, not a universal behavior of every supplied inference preset.

## 4. Sink construction at inference

**OBSERVED.** Sink is not a separate learned tensor in the supplied query-memory configuration. The first 3-latent block is inserted into cache slots 0..`sink_tokens-1`; because `current_start==0` does not count as recompute, all four denoising calls and the final timestep-0 context call overwrite those slots, leaving the first block's context-pass K/V as the durable sink (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:134-168`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:83-100`). Later rolls explicitly begin after `sink_tokens`, and later recomputations protect sink slots (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:138-160`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:656-670`).

**OBSERVED.** Under Relative RoPE, `start_frame=0` is applied to the three-frame sink grid, so its temporal IDs are 0, 1, and 2; “sink at id 0” means the sink range starts at zero, not that all sink tokens share one temporal ID (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:14-28`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:203-218`).

**OBSERVED ABSENCE.** `global_sink: true` in the single-prompt YAML does not add another mechanism in `CausalInferencePipeline`; the flag is read by the interactive/switch subclass specifically to decide whether prompt-switch recaching preserves sink (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:21-26`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/interactive_causal_inference.py:10-29`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/interactive_causal_inference.py:65-73`). Likewise, `use_sink_anchor: false` means sink KV is not included as context for recurrent query updates, although sink remains a direct tier in generator attention (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:137-142`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:283-310`).

## 5. Implemented overhead and reuse

### 5.1 Steady-state generator cost

**OBSERVED.** At the start of every transformer call after history exists, `get_kv()` projects all 4680 recurrent tokens through separate K and V linear layers; with one query group, the resulting KV pair is reused by all transformer blocks for that call (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:194-212`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:726-739`). There is no cache of projected memory KV across denoising calls: `get_kv()` is called anew by every `_forward_inference` invocation (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:686-740`).

**OBSERVED.** In each transformer block, memory K is re-RoPE'd, concatenated with sink and recent K/V, and consumed by the same final attention call; there is no separate generator-side memory-attention call (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:283-310`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:354-354`). The generic attention wrapper uses FlashAttention 2/3 when available and otherwise PyTorch scaled-dot-product attention (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/attention.py:21-66`). Thus memory is fused at the attention-kernel level by KV concatenation, but its projection, RoPE, and concatenation are not cached across calls.

**INFERRED.** In mature layout, each 3-frame query block attends to 15 frame-equivalents of KV (3 sink + 3 memory + 9 recent) instead of the 12 frame-equivalents allowed by sink+recent alone. Memory therefore increases self-attention score/value work by 25% for fixed query length, not total transformer FLOPs by 25% (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:169-224`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:283-310`). Relative mode additionally clones each layer's full K and V cache and re-RoPEs active sink/recent keys on every model call (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:138-168`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:203-268`).

### 5.2 Recurrent update cost

**OBSERVED.** On each logical eviction, the encoder runs two configured `MemoryCrossAttentionLayer`s over the fixed query state against the outgoing 3-frame KV, and each layer contains one cross-attention plus an FFN; connector projection and sigmoid gating then blend old and proposed states (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:8-34`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:38-68`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:144-158`). `use_batch_update: false` makes this immediate rather than buffered (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/configs/echo_infinity-long_inference.yaml:41-44`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/model/query_memory.py:124-142`).

**INFERRED.** A steady 3-latent output block therefore entails five full generator calls (four denoising plus one context), memory projection and memory-augmented generator attention on those calls once history is active, and one two-layer recurrent update on the first call when the window advances (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/pipeline/causal_inference.py:79-100`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:726-740`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/causal_model.py:797-828`). Text K/V projection is the notable cached/fused reuse outside this memory path (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/wan/modules/model.py:96-108`).

## 6. `inference_long_stream.py`: hour-scale operation and limitations

### 6.1 What it actually streams

**OBSERVED.** The 1-hour and 24-hour configs request 14,400 and 345,603 latent frames, both with the same fixed 12-frame cache, 3-frame sink, 3-frame query memory, and `pmax=21`; they differ mainly in rollout length/output folder (`/mnt/beegfs/siyuan/workspace/Echo-Infinity/inference/stream_long/configs/cfg_1h.yaml:1-25`, `/mnt/beegfs/siyuan/workspace/Echo-Infinity/inference/stream_long/configs/cfg_24h.yaml:1-25`). ## TL;DR

- The generation quantum is 3 VAE-latent frames; each quantum gets four denoising transformer calls plus one timestep-0 context-cache call.
- The durable cache representation of a completed block is its timestep-0 context-pass KV, not its last denoising-timestep KV.
- Eviction is delayed until the next block's first denoising call; memory reads old persistent cache before that call's cache roll is committed.
- Query memory consumes evicted KV from the last transformer layer only and updates once per newly advanced 3-frame block.
- Newly updated memory is unavailable to the eviction-triggering call and first appears on the next denoising call.
- Steady state is 3 sink + 3 learned-memory + 9 recent latent-frame equivalents; physical self-KV occupancy remains 12 frames.
- Sink is the first three latent frames after their timestep-0 context pass; Relative RoPE assigns them temporal IDs 0, 1, 2.
- Long Relative RoPE clamps current-query tail at ID 20 and re-RoPEs raw cached keys into bounded recycled positions every call.
- Long training exercises the same eviction and clamped-RoPE phases, though it uses a larger physical cache for streaming/BPTT while retaining a 12-frame active attention window.
- Mature memory adds 25% to self-attention score/value work versus the 12-frame sink+recent KV length, plus uncached memory projections and one two-layer recurrent update per block.
- Hour-scale attention state is constant, but `inference_long_stream.py` still allocates full-sequence noise and full latent output; only VAE decode/video writing is streamed.
- No periodic drift correction or mid-sequence resume exists; bounded Relative RoPE and gated fixed-size memory are the only explicit length-control mechanisms.
