# r5 长时域漂移 onset 分析(30s 分箱 + 双定义 onset + 回收判定)

**结论**
1. "~3 分钟可见漂移"只在弱意义上成立:onset 定义(b,累计斜率转正且不再回负)在 off/on-pilot4000 两臂中位数分别为 168.4s / 178.8s(≈2.8–3.0 min),接近 3 分钟;但 on-full8000 中位数仅 123.8s(≈2.1 min),明显更早。onset 定义(a,60s 滚动均值持续超 baseline+2σ 达 60s)三臂中位数为 209s / 173.2s / 203.5s,均比 3 分钟略晚(2.9–3.5 min)。**单例方差极大**(定义 b 范围 38.5s–468.9s),固定 180s 阈值对单个 case 并不可靠,只是量级上的中心估计。
2. 两种 onset 定义指向不同事件:定义(a)要求"持续偏离",off 臂 2/5 case(prompt_01/04)从未触发(全程未持续超阈值),说明 off 臂内部存在双峰行为(3 个稳定 case vs 2 个失控 case),而不是均匀的早期漂移。
3. 失控/回收分类(用 Q4/Q1 幅度 >2× 且 Q4≥Q3 判定"单调失控")复现且未推翻 `p2-longhorizon-verdict-r5-2026-07-28.md` 记录的表格:off 2/5 失控(case2/3,终值 194/200)、on-pilot4000 0/5 失控(5/5 回收)、on-full8000 3/5 失控(case0/1/2,峰值达 254.6)。四分段均值与整段 OLS/Theil-Sen 斜率均与原记录一致(见 §4 核对表),**无分歧,未覆盖原记录**。
4. 运动序列无冻结:15 个视频(3 臂 × 5 case)在 ≥20.6s 的低运动阈值扫描下均无冻结区间。
5. 推荐主指标:**onset 定义(a)(60s 滚动均值持续超 baseline+2σ 的首次时刻)**,因为它对"早期是否已经脱离统计正常区间"敏感,且对 off 臂内部的双峰结构(稳定 vs 失控)有区分力,而全程斜率会被 1–2 个离群 case 主导、掩盖大多数 case 仍然稳定的事实。推荐副指标:**末段回收比(末 10-chunk 均值 / 全程峰值)**,直接量化"回复力"这一 Stage A 记忆区别于 off/full8000 的关键性质,而全程净斜率无法区分"从未漂移"与"漂移后完全回收"这两种截然不同、但净斜率可能都接近 0 的情形。

## 6. 推荐指标

**主指标:onset 定义(a)——60s 滚动均值首次"此后持续 ≥60s 高于 baseline_mean+2·baseline_std"的时刻。**
理由:(i) 直接量化"多快脱离统计正常区间",比全程斜率更早给出信号,可用作固定长度评测(如仅跑 3–4 min)下的早期判据;(ii) 对 off 臂内部的双峰结构敏感——2/5 case 从未触发(真正稳定),3/5 触发(潜在失控前兆),而全程 Theil-Sen 斜率对 off 臂只给出一个均值 +0.219,掩盖了"3/5 才是问题源"这一结构信息。
**baseline 数值(干预需要更好,即中位数更晚且未触发比例更高):**
- off:中位数 209s,3/5 触发(2/5 从未触发)
- on-pilot4000:中位数 173s,5/5 触发
- on-full8000:中位数 204s,5/5 触发

**副指标:末段回收比 = 末 10-chunk(≈13.75s)saturation 均值 / 全程峰值。**
理由:全程净斜率无法区分"从未漂移"与"漂移后完全回收到低位"——两者净斜率可能都接近 0,但含义完全相反。回收比直接量化 Stage A 记忆报告过的"阻尼+回复力"性质,对判断未来抗漂移干预是否真正建立"回复力"(而非只是延后爆发)最敏感。
**baseline 数值(干预需要更低,即更接近峰值前的低位):**
- off:中位数 0.801(range 0.395–0.934)
- on-pilot4000:中位数 0.511(range 0.314–0.604)——当前唯一全部回收的谱系,是抗漂移干预的参照下限
- on-full8000:中位数 0.809(range 0.429–0.926)

## 方法与脚本

一次性分析脚本(未入库):`/tmp/r5_drift_onset.py`;运行:`/mnt/beegfs/yuheng/miniconda3/envs/helios/bin/python /tmp/r5_drift_onset.py`。核心步骤:(1) 加载三个 campaign 共 15 个 metrics JSON,断言 `n_chunks==349`;(2) chunk→秒用 `33/24` 换算;(3) 30s 分箱取窗口内 chunk 均值;(4) baseline = 每 case 自己前 60s(≈44 chunks)的 saturation 均值/标准差;(5) 定义(a)用 44-chunk(≈60s)滚动均值 + 前向持续性检查;(6) 定义(b)逐 chunk 累计 OLS(`np.linalg.lstsq`)斜率,并用随机/全枚举 Theil-Sen(pairwise median slope,≤4000 对或全枚举)在稀疏网格上交叉核对;(7) 失控/回收判定用四分段均值 Q1..Q4 与 Q4/Q1 比值;(8) 运动冻结扫描用 p90 相对阈值 + 连续游程长度。所有数值原样打印(3 位有效数字保留,未做额外四舍五入)。
